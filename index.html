Starta och anslut till möte

Rekommenderat arbetssätt
  1. Skicka eller vidarebefordra mötesinbjudan till konferensrummet
  2. 5 minuter innan mötet startar visas en grön knapp (Anslut)
  3. Tryck på den för att ansluta

Anslut manuellt (om ingen grön knapp visas)

  1. Tryck på Teams (för Teams-möten) eller Webex (för Webex-möten)
  2. Ange mötesinformation från din inbjudan
  3. Tryck på Anslut
Du hittar mötesinformation i din mötesinbjudan
Exempel
Mötesinformation för Teams
Mötes-ID: 123 456 789 123 456
Lösenord: XXXXXXXX
Mötesinformation för Webex
Mötesnummer: 123 456 789 123
Videoadress: username@example.webex.com

BYOD

  1. Om rummet är utrustat med USB-C kan du ansluta din egen dator
  2. Anslut USB-C kabeln till din dator
  3. Starta mötet på din dator
  4. Välj konferensrummets kamera, mikrofon och högtalare i mötet

Dela innehåll

Via kabel (rekommenderas)

  1. Anslut USB-C eller HDMI till din dator
  2. Tryck på Dela i möte på touchpanelen

Trådlöst (om tillgängligt)

Miracast (Windows)
  1. Tryck på Windows + K
  2. Välj mötesrummet
  3. Ange koden som visas på skärmen
AirPlay (Apple)
  1. Välj Skärmspegling på din enhet
  2. Välj mötesrummet
  3. Ange koden som visas på skärmen

(OBS! AirPlay fungerar endast när din enhet är ansluten till samma nätverk som videosystemet.)
